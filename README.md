### 2. EchoVault — Encrypted File Vault

An academic proof of concept exploring encrypted file storage and threshold-based key recovery.

- Demonstrates AES-256-GCM authenticated encryption.
- Implements a 3-of-5 Shamir Secret Sharing recovery concept.
- Includes a Spring Boot backend and React frontend.

**Technologies:** Java 21 · Spring Boot · React · H2 · MySQL

**Project note:** This is a partially implemented academic prototype. Its storage nodes are simulated and its API currently lacks authentication and authorization; it is not intended for real confidential data or public deployment.

[View repository →](https://github.com/Austin-Figo/EchoVault)

**Technologies:** Python · pandas · NumPy · scikit-learn
